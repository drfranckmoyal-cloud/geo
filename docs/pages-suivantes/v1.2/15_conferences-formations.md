# Conférences et formations — Dr Franck Moyal

## Enseigner oblige à rendre sa pratique transmissible

L’enseignement occupe une place importante dans mon activité.

Former ne consiste pas seulement à montrer un résultat clinique.

Il faut être capable de transformer une pratique en :
- décisions ;
- protocoles ;
- étapes reproductibles ;
- critères de choix ;
- limites ;
- stratégies de prévention et de maintenance.

C’est particulièrement vrai pour les domaines dans lesquels j’interviens le plus régulièrement :
**dentisterie esthétique, composites, planification, usures dentaires et réhabilitations adhésives.**

# Smileclub Formation

## Formation pratique pour chirurgiens-dentistes

Je suis **fondateur de Smileclub Formation**, organisme de formation destiné aux chirurgiens-dentistes.

Les formations sont construites autour d’une logique très clinique :
- comprendre ;
- planifier ;
- pratiquer ;
- pouvoir ensuite appliquer la méthode sur ses propres patients.

Les thèmes abordés comprennent notamment :
- usures dentaires ;
- stratification composite ;
- fermeture de diastème ;
- photographie clinique ;
- planification esthétique ;
- dyschromies ;
- éclaircissement ;
- inlays, onlays et overlays ;
- dentisterie adhésive.

Certaines formations sont aujourd’hui également référencées et distribuées via Blendi.

**Voir mon profil de formateur Blendi**  
https://blendi.fr/formateurs/franck-moyal

# Usures dentaires

## Du diagnostic à la réhabilitation

La prise en charge des usures constitue aujourd’hui l’un de mes principaux thèmes d’enseignement.

Les formations abordent notamment :
- diagnostic différentiel ;
- érosion, attrition et abrasion ;
- lecture des modèles d’usure ;
- dimension verticale ;
- planification ;

- choix direct / indirect ;
- gestion des secteurs antérieurs et postérieurs.

# Pourquoi enseigner les usures ?

Parce qu’il s’agit de situations qui peuvent sembler complexes lorsque l’on n’a pas encore structuré sa méthode.

Le traitement associe souvent :
- diagnostic étiologique ;
- analyse fonctionnelle ;
- planification esthétique ;
- gestion de la DVO ;
- dentisterie adhésive ;
- composite ;
- céramique ;
- laboratoire.

La transmission oblige à clarifier ce raisonnement.

C’est aussi l’une des raisons pour lesquelles la notion de **planification précise avant le premier geste** revient constamment dans ma pratique.

# Formation et TCA

Les TCA constituent un autre axe de transmission en développement.

L’objectif n’est pas de transformer le chirurgien-dentiste en spécialiste de psychiatrie.

Il est de lui permettre de :
- reconnaître certaines manifestations bucco-dentaires ;
- dépister ;
- prévenir ;
- orienter ;
- protéger ;
- savoir à quel moment restaurer ;
- connaître les spécificités des patients vulnérables.

Cette logique est également au cœur du projet DentCA.
