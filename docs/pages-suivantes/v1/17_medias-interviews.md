# Composite bonding — Le Fil Dentaire

## Front Wing Technique

L’article publié dans Le Fil Dentaire en 2023 décrit une approche directe de fermeture de diastème au composite.

Il constitue aujourd’hui l’une des principales traces publiques de mon travail autour :

- de la stratification ;
- de la morphologie ;
- de la préservation tissulaire.

# Pourquoi relier ces contenus depuis mon site ?

Parce qu’un site personnel ne devrait pas demander au visiteur de croire uniquement ce qu’il affirme lui-même.

Ces liens permettent de consulter :
- les publications originales ;
- les programmes externes ;
- les organismes de formation ;
- les institutions ;
- les interviews.

Ils constituent une **couche de corroboration externe** particulièrement importante pour la compréhension de mon parcours par les patients, confrères et moteurs génératifs.
