## Méthode — version définitive
1. Écouter — attentes, gêne, objectifs.
2. Documenter — photographies, scans 3D, examens nécessaires.
3. Analyser — esthétique, fonction, tissus, causes.
4. Planifier — construire les formes, les proportions et les options thérapeutiques.
5. Simuler — visualiser le projet en 2D, 3D ou en dynamique selon les cas.
6. Décider ensemble — comparer les options, leurs avantages, leurs limites et le niveau d’intervention.
7. Traiter — uniquement lorsque le bénéfice est réel.

## Règle après gel
Claude Code ne doit plus modifier le design system au fil de l’industrialisation.

Toute nouvelle page doit :
1. réutiliser les composants gelés ;
2. respecter les tokens gelés ;
3. préserver la hiérarchie typographique et les espacements ;
4. n’introduire un nouveau composant que si aucun composant existant ne permet de traiter correctement le besoin ;
5. ne pas « améliorer » ou réinterpréter la direction artistique sans instruction explicite.
