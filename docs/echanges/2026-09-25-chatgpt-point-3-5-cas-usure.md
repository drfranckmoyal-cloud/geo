# 1. OBJECTIF

Créer UNE seule page forte capable de remplir simultanément plusieurs fonctions :

1. documenter un cas clinique réel ;
2. montrer l'importance de l'anamnèse dans le diagnostic des usures dentaires ;
3. montrer que l'analyse de l'origine des lésions précède le choix esthétique ;
4. documenter une prise en charge par facettes minimalement invasives ;
5. renforcer les entités thématiques du site :
   - Franck Moyal ;
   - dentisterie esthétique ;
   - facettes dentaires ;
   - usures dentaires ;
   - planification esthétique ;
   - préservation tissulaire ;
6. constituer un contenu particulièrement lisible et extractible par les moteurs de recherche et les moteurs génératifs.

Le contenu doit donc fonctionner à la fois comme :

**cas clinique + contenu pédagogique + preuve d'expertise.**

---

# 2. PRINCIPE ÉDITORIAL

Le sujet principal n'est PAS :

> Un patient a reçu des facettes.

Le sujet est :

> Une demande esthétique liée à un sourire usé conduit à rechercher l'origine des lésions avant de décider du traitement. L'anamnèse met ici en évidence une ancienne habitude mécanique très particulière, permettant de comprendre certaines lésions observées. Le projet esthétique est ensuite réalisé par une approche restauratrice minimalement invasive.

La séquence éditoriale doit donc être :

**demande → observation → enquête clinique/anamnèse → compréhension des lésions → projet esthétique → traitement conservateur → résultat.**

C'est cette logique qui différencie cette page d'un simple avant/après.

# 3. DONNÉES CLINIQUES VALIDÉES

Patient :

**64 ans.**

Motif de consultation :

**consultation esthétique afin de réhabiliter un sourire qu'il perçoit comme abîmé, usé et vieilli.**

Examen clinique et radiographique :

**usures importantes, particulièrement visibles dans le secteur antérieur.**

L'anamnèse approfondie révèle une habitude ancienne :

**pendant plusieurs années, lorsqu'il était plus jeune, le patient intercalait régulièrement un carreau de sucre entre ses dents.**

Cette habitude a participé à la création de lésions d'abrasion particulières.

Traitement esthétique :

**facettes minimalement invasives.**

POINT ESSENTIEL :

Franck demande explicitement que le caractère **minimalement invasif** des facettes soit mis en avant.

# 5. ATTENTION AU TERME « ABRASION »

L'habitude mécanique d'interposition du carreau de sucre constitue ici une donnée anamnestique permettant d'expliquer certaines lésions observées.

Ne pas transformer la page en démonstration générale selon laquelle :

**le sucre provoque mécaniquement l'usure dentaire.**

Ce serait une simplification incorrecte.

Le message doit rester lié à CE cas :

**l'interposition répétée d'un objet/aliment solide entre certaines dents constitue une contrainte mécanique répétée susceptible d'expliquer la morphologie particulière de certaines lésions observées chez ce patient.**

Le caractère remarquable du cas vient de l'identification de cette habitude lors de l'interrogatoire.

# 6. ANGLE DIAGNOSTIQUE CENTRAL

La page doit montrer que devant des usures dentaires, l'observation seule ne suffit pas toujours.

Le praticien cherche à comprendre :

- la localisation ;
- la morphologie ;
- la répartition ;
- le contexte ;
- les habitudes du patient.

Dans ce cas précis, c'est une **anamnèse approfondie** qui a permis de retrouver une habitude ancienne cohérente avec certaines lésions.

Ne pas généraliser cette cause aux autres patients présentant des usures.
