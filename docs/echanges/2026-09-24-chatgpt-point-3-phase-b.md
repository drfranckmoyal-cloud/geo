# 16. RAISONNEMENT THÉRAPEUTIQUE COMMUN

C'est le cœur de la page.

Franck précise :

Dans la grande majorité de ces situations, un éclaircissement est réalisé avant l'érosion-infiltration.

Pourquoi ?

L'éclaircissement permet de :

**réduire le delta de teinte entre la dent et la tache.**

Autrement dit :

* diminuer le contraste ;
* rapprocher visuellement la tache et le reste de la dent ;
* faciliter ensuite son intégration esthétique lors de l'érosion-infiltration.

La seconde idée fondamentale est :

**préserver au maximum les tissus dentaires.**

L'érosion-infiltration permet de traiter certaines taches avec une perte de substance très limitée.

Un composite de surface peut parfois être réalisé pour combler le petit défaut créé lorsque cela est nécessaire.

IMPORTANT :

Ne pas écrire que le composite de surface a été réalisé dans ces deux cas si ce n'est pas explicitement documenté.

Le présenter uniquement comme une possibilité technique.

## H2 — Cas 2 : MIH sur une dent dyschromiée après un traumatisme

Expliquer :

## H2 — Pourquoi privilégier une approche conservatrice ?

Expliquer :

L'objectif est de traiter la tache en limitant autant que possible la perte de substance dentaire.

L'érosion-infiltration constitue dans les situations indiquées une approche particulièrement conservatrice.

Lorsque la préparation superficielle crée un petit défaut nécessitant d'être restauré, un apport localisé de composite peut parfois compléter le traitement.

Ne pas écrire :

* totalement non invasif ;
* aucune perte de substance ;
* 100 % réversible ;
* résultat garanti.

---

## H2 — Ce que ces deux cas permettent de comprendre

Idée :

**Le traitement esthétique d'une tache ne commence pas nécessairement par son masquage avec un matériau restaurateur. La modification préalable du contraste puis l'utilisation d'une technique d'érosion-infiltration peuvent permettre, lorsque l'indication s'y prête, une approche beaucoup plus conservatrice.**
