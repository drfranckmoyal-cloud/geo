# 1. LE PROJET

Nous construisons le site professionnel personnel du **Dr Franck Moyal**, chirurgien-dentiste à Paris.

Ce n’est pas :
- un site de cabinet dentaire généraliste ;
- un site vitrine standard ;
- une landing page publicitaire ;
- un simple portfolio de cas cliniques.

Le site doit devenir à la fois :

1. **la source canonique de l’entité “Dr Franck Moyal” sur le web** ;
2. **une vitrine haut de gamme de sa pratique clinique** ;
3. **un hub de contenus de référence sur ses domaines d’expertise** ;
4. **un actif SEO local et thématique** ;
5. **un actif GEO**, pensé pour être compris, cité et recommandé par les moteurs génératifs : ChatGPT, Gemini, Claude, Perplexity, Google AI Overviews/AI Mode, Copilot/Bing.

Le site doit être suffisamment solide pour que des requêtes non brandées comme :
- « quel dentiste esthétique à Paris ? »
- « quel dentiste fait du composite bonding à Paris ? »
- « qui consulter pour des dents usées ? »
- « quel dentiste prend en charge l’érosion dentaire ? »
- « quel dentiste connaît bien les conséquences dentaires des TCA ? »

puissent progressivement conduire les moteurs à identifier Franck Moyal comme une réponse pertinente.

# 2. POSITIONNEMENT CLINIQUE

Le site repose sur **deux piliers principaux de même importance**.

## Pilier 1 — Dentisterie esthétique et adhésive

Territoires :
- bilan esthétique personnalisé ;
- planification esthétique ;
- SmileCloud ;
- composite bonding ;
- stratification composite ;
- facettes ;
- éclaircissement / blanchiment dentaire ;
- taches et dyschromies ;
- érosion-infiltration / ICON.

Le ton doit être :
- esthétique ;
- désirable ;
- affirmé ;
- précis ;
- haut de gamme ;
- jamais cheap ou sur-commercial.

La philosophie :
**transformer un sourire avec le niveau d’intervention le plus adapté, en recherchant précision, beauté naturelle et préservation tissulaire.**

## Pilier 2 — Usures dentaires

Territoires :
- diagnostic des usures ;
- attrition ;
- bruxisme ;
- érosion ;
- usures multifactorielles ;
- dents courtes / aplaties ;
- prévention ;
- réhabilitation adhésive ;
- dimension verticale lorsque pertinente ;
- reconstruction esthétique ET fonctionnelle.

La philosophie :
**comprendre avant de reconstruire.**

Le traitement des usures doit toujours relier :
**esthétique + fonction + préservation.**

Les troubles des conduites alimentaires ne constituent pas un troisième pilier équivalent.

Ils forment une **expertise spécifique très différenciante**, reliée au pilier Usures / Érosion.

Axes :

- prévention ;
- érosion dentaire ;
- anorexie restrictive, y compris sans vomissements ;
- boulimie ;
- reflux / vomissements ;
- salive / sécheresse buccale ;
- réhabilitation au bon moment ;
- coordination multidisciplinaire.

Le site doit clairement faire comprendre que Franck Moyal possède une activité spécifique et documentée dans ce domaine.

# 4. FIL ROUGE CLINIQUE GLOBAL

Trois mots doivent traverser tout le site :

## ESTHÉTIQUE
Rechercher un résultat harmonieux, naturel, maîtrisé.

## FONCTION
Ne pas traiter la dent isolément lorsqu’un problème fonctionnel est impliqué.

## PRÉSERVATION
Conserver au maximum les tissus dentaires.

Ces trois dimensions sont reliées par la notion de **gradient thérapeutique** :
choisir, pour chaque situation, la solution la plus conservatrice compatible avec l’objectif clinique et esthétique.

Important :
le gradient thérapeutique n’est pas une raison pour être timide sur l’esthétique.
Le site doit aussi **donner envie**, particulièrement sur les pages Facettes, Composite Bonding et Éclaircissement.

# 5. MÉTHODE DE CONSULTATION

Une autre signature du site est la méthodologie clinique.

Séquence :

**Écouter → Documenter → Analyser → Planifier → Simuler → Décider ensemble → Traiter**

Le bilan peut associer :
- écoute des attentes ;
- photographie clinique calibrée ;
- scans / empreintes numériques 3D ;
- radiographies si nécessaires ;
- analyse esthétique ;
- analyse fonctionnelle si pertinente ;
- planification numérique ;
- SmileCloud ;
- simulation 2D / 3D / dynamique selon les cas ;
- discussion des variantes avec le patient.

La planification est un **outil de co-décision**, pas seulement un outil technique.

# 9. TON ÉDITORIAL

Le ton est :
- sûr ;
- élégant ;
- précis ;
- pédagogique ;
- clinique ;
- aspirationnel sur l’esthétique ;
- sans langage marketing bas de gamme.

- anxieux ;
- timide ;
- défensif ;
- excessivement prudent au point de diluer la compétence ;
- rempli de disclaimers.

Sur les pages esthétiques :
**on vend réellement le bénéfice esthétique.**

Sur les pages médicales / usures / TCA :
**on garde une précision scientifique élevée.**

# 10. STRATÉGIE SEO / GEO

Chaque page doit servir trois fonctions :

1. **répondre au patient** ;
2. **se positionner sur Google** ;
3. **fournir des passages directement récupérables par les IA**.

Règles :
- H1 unique ;
- H2 formulés comme intentions ou questions réelles ;
- blocs de réponse directe de 40–100 mots ;
- maillage interne fort ;
- auteur clairement identifié ;
- sources scientifiques lorsque nécessaire ;
- entités nommées explicitement ;
- contenu HTML crawlable ;
- données structurées cohérentes ;
- pas de keyword stuffing ;
- pas de pages artificielles créées uniquement pour une variante de mot-clé.

# 12. POURQUOI UN GOLDEN MASTER

Le principal risque du projet est une perte de continuité entre :
- stratégie ;
- contenu ;
- direction artistique ;
- implémentation finale.

Pour éviter cela, **Claude Code ne doit pas construire tout le site immédiatement**.

Il doit d’abord construire uniquement :

1. Homepage
2. Page Franck Moyal
3. Page Usures dentaires

Ces trois pages servent de **golden master**.

Nous validons :
- proportions ;
- rythme ;
- typographie ;
- couleurs ;
- espaces ;
- traitement des images ;
- navigation ;
- composants ;
- responsive ;
- CTA ;
- blocs éditoriaux.

Une fois validés :
**les composants sont gelés**.

Le reste du site sera ensuite dérivé de ce système au lieu d’être redessiné page par page.
