# DESIGN SYSTEM — GOLDEN MASTER
## Direction visuelle

Le site doit évoquer :
- cabinet esthétique haut niveau ;
- sobriété ;
- précision ;
- calme ;
- architecture éditoriale contemporaine ;
- chaleur discrète ;
- aucune esthétique « clinique froide » ;
- aucun look « startup SaaS » ;
- aucun look « cabinet dentaire générique ».

## Palette

Base :
- noir doux : `#171715`
- ivoire : `#F4F0E8`
- blanc cassé : `#FAF8F3`
- gris chaud : `#D8D3CA`
- vert sauge sombre : `#5E685D`
- vert sauge clair : `#B9C1B5`

Règle :
- 80 % neutres ;
- 15 % ivoire / gris chaud ;
- 5 % vert sauge.
- jamais de grands aplats verts saturés.

## Typographie

### Titres
Une serif contemporaine, élégante, à contraste modéré.
Exemples de direction :
- Canela-like
- Editorial New-like
- Cormorant Garamond si solution open-source propre

### Texte
Sans-serif neutre et précise.
Exemples :
- Inter
- Manrope
- Neue Haas-like si licence disponible

### Tailles desktop
- H1 : 64–76 px
- H2 : 42–52 px
- H3 : 26–32 px
- Lead : 22–26 px
- Body : 17–19 px
- Small : 14–15 px

### Mobile
- H1 : 42–48 px
- H2 : 32–38 px
- Body : 17–18 px

## Grille

Desktop :
- max-width contenu : 1240 px
- largeur texte éditorial : 720–820 px
- grille 12 colonnes

Mobile :
- marges : 20–24 px

## Espacement

Sections principales :
- desktop : 112–144 px
- mobile : 72–88 px

Espacement titre → texte :
- 24–32 px

Texte → CTA :
- 32–40 px

## Boutons

### Primaire
Fond noir doux.
Texte blanc cassé.
Pas de pill géant.
Hauteur : 50–54 px.
Rayon : 2–4 px.

### Secondaire
Texte noir + flèche.
Pas de contour lourd.

## Images

Style :
- photographie clinique ou portrait réel ;
- cadrage éditorial ;
- lumière naturelle ;
- aucun stock photo générique ;
- aucune dent 3D glossy ;
- aucune image « sourire parfait » cliché.

Cas cliniques :
- fond neutre ;
- recadrage constant ;
- avant / après de même échelle ;
- légende sobre ;
- consentement documenté.

## Iconographie

Minimaliste, linéaire.
Pas d’icônes dentaire cartoon.
Pas d’emoji dans le site.

## Cartes

Très peu.
Préférer :
- blocs éditoriaux ;
- lignes ;
- changements de fond ;
- composition asymétrique.

Éviter un site composé de dizaines de cards.

## Animations

Très discrètes :
- fade + translate 8–12 px ;
- 250–450 ms ;
- pas de parallax agressif ;
- pas de carrousel automatique ;
- respecter `prefers-reduced-motion`.

## Ton visuel

Le site doit faire comprendre :
**« précision, maîtrise, esthétique, conservation »**
avant même de lire le texte.
