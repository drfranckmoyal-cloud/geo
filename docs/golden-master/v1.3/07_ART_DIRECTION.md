# 07 — ART DIRECTION
## Golden Master — drfranckmoyal.fr
## Version 1.0

Ce document verrouille la **direction artistique** du Golden Master.

L’objectif n’est pas de fournir une simple ambiance ou quelques adjectifs.
Il s’agit de définir une **grammaire visuelle précise**, suffisamment claire pour que Claude Code puisse exécuter le projet sans réinterpréter l’intention.

---

# 1. INTENTION GÉNÉRALE

Le site doit transmettre immédiatement :

**maîtrise — précision — esthétique — calme — confiance — sophistication discrète**

Il doit évoquer davantage :
- une publication éditoriale haut de gamme ;
- un studio d’architecture intérieure sophistiqué ;
- une maison de design scandinave ;
- une clinique esthétique extrêmement maîtrisée ;

que :
- un site de cabinet dentaire standard ;
- une clinique médicale froide ;
- une startup ;
- une landing page marketing.

Le résultat doit être **premium sans ostentation**.

Le visiteur doit ressentir que :
- rien n’est laissé au hasard ;
- la pratique est exigeante ;
- le niveau esthétique est élevé ;
- la technologie existe mais reste au service du projet ;
- le soin est personnalisé ;
- le site est construit par quelqu’un qui maîtrise son sujet.

---

# 2. MOTS-CLÉS VISUELS

## À rechercher
- éditorial
- scandinave
- chaleureux
- minéral
- précis
- silencieux
- architectural
- haut de gamme
- naturel
- texturé
- intemporel
- contemporain
- sobre
- humain
- clinique sans froideur

## À éviter
- médical bleu/blanc
- glossy
- tech startup
- SaaS
- cyber
- futuriste
- “luxury black & gold”
- magazine de mode trop spectaculaire
- clinique Dubaï trop ostentatoire
- esthétique Instagram / influenceur
- minimalisme vide sans contenu

# 3. PALETTE

## Base principale
- Noir doux : `#171715`
- Blanc cassé : `#FAF8F3`
- Ivoire : `#F4F0E8`
- Gris chaud : `#D8D3CA`

## Accent principal
- Vert sauge sombre : `#5E685D`

## Accent secondaire
- Vert sauge clair : `#B9C1B5`

## Usage recommandé
- 70–80 % : blanc cassé / ivoire
- 10–15 % : noir doux
- 5–10 % : gris chaud
- 5 % maximum : vert sauge

Le vert ne doit jamais devenir le thème principal.
Il sert de ponctuation visuelle :
- petit label ;
- filet ;
- survol ;
- micro-zone de fond ;
- détail typographique.

## Interdits
- bleu médical
- turquoise
- violet cosmétique
- or métallique
- beige trop jaune
- gradients colorés
- vert saturé

---

# 4. TYPOGRAPHIE

## Titres
Style :
- serif éditoriale ;
- élégante ;
- contrastée sans être fragile ;
- légèrement expressive ;
- lisible à grande taille.

Direction souhaitée :
- Canela-like
- Editorial New-like
- Tiempos-like
- Cormorant Garamond si choix open-source nécessaire

Le titre doit donner :
**culture éditoriale + distinction + douceur**

## Texte courant
Sans-serif neutre et très lisible.

Direction :
- Inter
- Manrope
- Suisse-like
- Neue Haas-like si disponible légalement

Le texte courant doit donner :
**précision + clarté + rigueur clinique**

## Hiérarchie desktop
- H1 : 64–76 px
- H2 : 42–52 px
- H3 : 26–32 px
- Lead : 22–26 px
- Body : 17–19 px
- Small / meta : 14–15 px

## Mobile
- H1 : 42–48 px
- H2 : 32–38 px
- H3 : 24–28 px
- Lead : 20–22 px
- Body : 17–18 px

## Règle
Le contraste serif / sans-serif est un **élément d’identité** :
- serif = désir, image, personnalité ;
- sans-serif = précision, clinique, lisibilité.

---

# 5. DENSITÉ & RESPIRATION

Le site doit respirer.

## Sections principales
Desktop :
- 112–144 px de marge verticale

Mobile :
- 72–88 px

## Largeur texte
Texte éditorial :
- 720–820 px max

## Largeur générale
Container :
- 1180–1240 px max

## Règle
Mieux vaut :
- 4 blocs forts bien espacés

que :
- 9 petites sections compressées.

---

# 6. COMPOSITION

La composition doit être **éditoriale** et parfois légèrement asymétrique.

## Favoriser
- texte décalé ;
- grand vide ;
- image légèrement hors axe ;
- alternance des masses ;
- titres très grands ;
- bloc court sur fond ivoire ;
- respiration importante.

## Éviter
- grille de cards uniforme ;
- alignement centre partout ;
- sections identiques répétées ;
- effet template ;
- alternance gauche/droite mécanique sur toute la page.

Chaque page doit garder la même grammaire, mais pas sembler copiée-collée.

---

# 7. HOME — DIRECTION SPÉCIFIQUE

La homepage doit être une **page manifeste**.

## Hero
- très peu de texte ;
- H1 dominant ;
- grand blanc ;
- portrait ou visuel réel fort ;
- pas d’illustration décorative.

## Impression
Le visiteur doit comprendre :
**“ce praticien a une vraie direction esthétique et une vraie méthode.”**

## Piliers
Les deux piliers doivent être présentés comme deux territoires majeurs, pas comme deux cartes de services banales.

Préférer :
- grands titres ;
- texte court ;
- images / détails ;
- liens sobres.

---

# 8. PAGE FRANCK MOYAL — DIRECTION SPÉCIFIQUE

Cette page doit être :
**incarnée, éditoriale, crédible, personnelle**

## Hero
- portrait réel ;
- H1 simple ;
- peu d’information secondaire.

## Corps
- sections textuelles ;
- quelques images ;
- phrases fortes en grand format ;
- éléments de preuve intégrés naturellement.

Éviter :
- CV chronologique brut ;
- timeline gadget ;
- mur de logos ;
- grille de badges.

---

# 9. PAGE USURES — DIRECTION SPÉCIFIQUE

La page Usures doit être plus clinique, sans devenir froide.

## Codes
- structure très lisible ;
- schémas simples ;
- images cliniques propres ;
- fond majoritairement clair ;
- quelques blocs vert sauge très discrets.

## Sensation
**expertise calme**

Le lecteur doit sentir :
- diagnostic ;
- méthode ;
- sérieux ;
- capacité à traiter des situations complexes.

---

# 10. IMAGES

## Portrait
- lumière naturelle ;
- cadrage éditorial ;
- attitude calme ;
- regard assuré ;
- arrière-plan architectural ou neutre ;
- tenue professionnelle sobre.

Interdit :
- bras croisés / sourire forcé / cabinet blanc standard ;
- blouse blanche cliché ;
- fond bleu médical ;
- photo corporate stock.

## Images cliniques
- prises de vues réelles ;
- cadrage cohérent ;
- fond neutre ;
- colorimétrie homogène ;
- aucune illustration 3D générique.

## Avant / après
- taille identique ;
- cadrage identique ;
- pas de flèches marketing ;
- pas de cercle rouge ;
- légende minimale.

## Images d’ambiance
Seulement si elles sont réelles et liées au lieu / à la pratique.

---

# 11. UI — BOUTONS & LIENS

## Primary CTA
- fond `#171715`
- texte `#FAF8F3`
- hauteur 50–54 px
- padding horizontal généreux
- radius 2–4 px
- typo sans-serif medium
- aucun effet 3D

## Secondary CTA
- texte simple ;
- flèche fine ;
- underline au hover ou mouvement discret.

## Hover
- subtil ;
- 150–250 ms ;
- aucun zoom spectaculaire.

---

# 12. HEADER

## Desktop
- fin ;
- beaucoup d’air ;
- logo / nom à gauche ;
- navigation centrale ou droite ;
- CTA rendez-vous discret mais visible.

## Scroll
Peut devenir légèrement plus compact.

## Mobile
- menu simple ;
- pas de panneau animé spectaculaire ;
- pas d’icône fantaisie.

---

# 13. FOOTER

Le footer doit être utile au SEO / GEO et rester visuellement calme.

Inclure :
- navigation piliers ;
- page Franck ;
- publications ;
- activité hospitalière ;
- contact ;
- mentions légales ;
- éventuellement adresse / téléphone.

Pas de mur de liens.

---

# 14. CARDS

Utiliser les cards uniquement quand elles apportent une vraie structure.

## Acceptées
- cas cliniques ;
- 2 piliers ;
- 3 preuves / médias ;
- articles.

## Interdit
Transformer chaque section en carte.

Pas :
- d’ombres lourdes ;
- de coins à 20 px ;
- de glow ;
- de verre dépoli.

---

# 15. ICONOGRAPHIE

Si nécessaire :
- linéaire ;
- monochrome ;
- géométrique ;
- très fine.

Pas :
- dent cartoon ;
- smiley ;
- pictogrammes médicaux standards ;
- icônes colorées.

---

# 16. ANIMATIONS

Seulement :
- opacity ;
- translateY 8–12 px ;
- 250–450 ms.

## Jamais
- parallax lourd ;
- scroll-jacking ;
- zoom ;
- rotation ;
- éléments flottants ;
- carrousels automatiques.

Respecter :
`prefers-reduced-motion`

---

# 17. MOBILE

Le mobile n’est pas une version compressée du desktop.

Il doit conserver :
- grands titres ;
- respiration ;
- hiérarchie ;
- rythme ;
- sensation premium.

## Attention particulière
- H1 doit rester spectaculaire sans casser en 5 lignes ;
- CTA toujours facilement accessible ;
- aucun tableau large ;
- accordéons uniquement si réellement utiles.

---

# 18. FORMULE DE DIRECTION ARTISTIQUE

> Construire un site éditorial premium, calme et très maîtrisé, à l’esthétique scandinave chaleureuse, combinant sophistication discrète, rigueur clinique et désirabilité esthétique, sans aucun code visuel de site dentaire générique ni de produit SaaS.

Cette phrase doit rester le **test de cohérence** de toutes les décisions visuelles.

---

# 19. TEST VISUEL

Avant validation, demander :

**Si on retire tout le texte et qu’on garde uniquement la mise en page, les images et la typographie, le site ressemble-t-il encore à une pratique esthétique haut de gamme et singulière ?**

Si la réponse est non :
le design n’est pas assez fort.
